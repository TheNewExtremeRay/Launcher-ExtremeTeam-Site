SECTION 06

AI Theme Generation (Bring-Your-Own-Key)

  1. The Software can generate color palettes from a text description using a third-party large-language-model API (Cerebras). This feature is optional and requires your own API key ("BYOK").
  2. Obtaining the key: you must register with the AI provider yourself and obtain an API key under their terms. FractalLabs is not affiliated with the AI provider and receives no revenue, share, or data from your key.
  3. Your key stays on your device. It is stored locally (default: ~/.FractalLauncher/cerebras_api_key.txt, plain text — you acknowledge this storage method and its risks). The key is transmitted only to the AI provider's official API endpoint when you request theme generation.
  4. Prompts go to the AI provider. Any description you type for theme generation is sent to the AI provider, together with your API key, subject to their privacy policy and terms. Do not send personal, confidential or sensitive information in prompts.
  5. AI output is provided as-is. Generated palettes may be inaccurate, unattractive, or unsuitable. FractalLabs does not review, endorse or warrant any AI output. You are responsible for evaluating generated themes before use.
  6. Compliance with the AI provider's terms (rate limits, prohibited uses, content policies) is your responsibility. Abuse of your key or of the provider's API is between you and the provider.
  7. FractalLabs may change or remove the AI integration at any time (e.g., if the provider's API changes).
